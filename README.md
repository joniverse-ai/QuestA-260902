# 에이전트 하네스 톺아보기 — 프로젝트 과제

Claude Code의 권한 규칙(allow/ask/deny) 완화가 과업 완료 시간에 미치는 영향을 측정하는 실험.

## 구조

```
experiment-01.md          ← 실험 보고서 (가설, 설계, 결과)
fixtures/
  parse-log/sample.log    ← 과업 1: 로그 파싱
  refactor-util/util.py   ← 과업 2: 타입 힌트 추가
  fix-failing/test_me.py  ← 과업 3: 실패 테스트 수정
```

## 가설 요약

> Claude Code의 프로젝트 내 파일 접근과 안전한 명령 실행에 allow 규칙을 설정하면, 기본(ask-all) 대비 과업 완료 시간이 단축되며 오류율은 증가하지 않는다.

## 루브릭 대응

| 학습목표 | 평가기준 | 보고서 위치 |
|---------|---------|------------|
| 가설의 근거를 명확하게 파악 | 근거 조사 + 등급 표기 | §3 배경 근거 (6개, [학술]/[벤더]/[공식 문서] 표기) |
| 공정한 비교 설계 | 실험 범위 적절성 | §4 실험 설계 (고정/조작/측정/사전 판정식 분리) |
| 불편을 가설로 변환 | 반증 가능한 가설 | §2 가설 (반증 조건 명시) |
